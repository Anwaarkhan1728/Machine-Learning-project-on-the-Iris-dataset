# Machine-Learning-project-on-the-Iris-dataset

A Machine Learning web app that predicts the species of an Iris flower
based on its sepal and petal measurements.

## 🚀 Features
- Trains **4 ML models** (Logistic Regression, Random Forest, SVM, KNN)
- Automatically picks the **best model** by cross-validation score
- Beautiful **Streamlit UI** with sliders, charts, and confidence scores
- Saves the best model as `models/iris_best_model.pkl`
